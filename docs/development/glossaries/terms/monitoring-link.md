# Monitoring Link

- Bounded context: Observability, owned by `api-server` as Platform data; surfaced by `dashboard` and `cli`.
- Definition: A named link from a Platform to an external monitoring user interface that belongs to that runtime — for example the Grafana that Omnistat brings for a Slurm Platform. swallow stores the name and URL as owned display data and shows them where the Platform is managed. Operators register links; Swallow also registers `Omnistat Grafana` itself when it installs Omnistat.
- Allowed meaning: A `name` and an absolute `http`/`https` `url` attached to one Platform, at most ten per Platform with names unique within it, replaced as a whole list when edited. It answers "where is this runtime's own monitoring?" so an operator can move from swallow to it in one click. A successful Omnistat install replaces (or adds) only the link named `Omnistat Grafana`, and uninstalling the Platform removes only that link; other links stay operator-owned.
- Disallowed meaning: Not a metrics Integration — swallow never connects to, authenticates against, health-checks, or queries a Monitoring Link, and its usage charts keep reading the Site metrics backend. Not a credential holder (a link carries no secret). Not a Grafana deep link generated by swallow (the metrics Integration's optional Grafana URL is a separate setting). Not a way to make swallow scrape the runtime's collectors.
- Synonyms: Platform monitoring link.
- Deprecated terms: None.
- Examples: "Add the Monitoring Link `Omnistat Grafana` to `research-slurm` so operators reach Omnistat's dashboards from the Platform page." / "Clearing a Platform's Monitoring Links does not stop Omnistat; it only removes the shortcut from swallow." / "Server detail still shows CPU and GPU charts from the Site Prometheus while the Slurm Platform links to Omnistat." / "The Slurm deployment installed Omnistat, so the Platform page already shows `Omnistat Grafana` pointing at the primary controller."
- Related terms: Platform, Integration, Exporter Ownership, Server, Omnistat.
- Change note: Added 2026-10-12 with the monitoring integration work so a runtime with its own complete monitoring stack (Omnistat on Slurm) is reachable from swallow without becoming a second metrics backend; see the 2026-10-12 amendment of decision 003. 2026-10-21 (decision 063): Swallow registers and removes the `Omnistat Grafana` link when it installs and uninstalls Omnistat.
