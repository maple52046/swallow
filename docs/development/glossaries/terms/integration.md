# Integration

- Bounded context: swallow-wide.
- Definition: A registered external system that swallow talks to, scoped to exactly one Site. swallow owns the registry of Integrations; no external system knows which systems swallow should talk to.
- Allowed meaning: A swallow-owned record identified by an opaque, stable `integrationId` — persisted in every Server source, so it must never be reissued for a different system — carrying `siteId`, a `kind`, an `endpoint`, a write-only `credentialRef`, and an `enabled` flag. Kinds are `provisioner` (MAAS — read inventory, deploy and release operating systems), `metrics` (central TSDB — query with PromQL), and `platform` (Kubernetes API or Slurm — read live membership and, for Kubernetes, manage in-cluster resources). An Integration may be registered but paused. A `platform` Integration is created only by a successful Swallow deployment's completion hook; operators register `provisioner` and `metrics` Integrations, but not `platform` ones.
- Disallowed meaning: Not a Site, a Server, a Platform, or the external system itself; the Integration is swallow's registration of it. A credential is never returned by any API in any form, including redacted — it is write-only. The `platform` kind names the external Kubernetes/Slurm technology, not the `Platform` aggregate. A `platform` Integration is not an operator-facing way to attach a runtime Swallow did not deploy: the public create API rejects `kind=platform` ([decision 032](../../../decisions/032-self-deployed-platform-management.md)).
- Synonyms: None.
- Deprecated terms: None.
- Examples: "A `provisioner` Integration reconciles machines into Server projections." / "A MAAS spanning two Sites is two Integrations, because an Integration serves exactly one Site."
- Related terms: Site, Server, OS Provisioning Provider, Staleness, Machine.
- Change note: Migrated 2026-09-05 from the narrative `docs/glossaries/site.md` (reorg D2). The kind names the external technology, kept per [decision 014](../../../decisions/014-platform-resource-language.md) / [015](../../../decisions/015-platform-term-disambiguation.md); the canonical kind is `platform` (`cluster` is a one-release deprecated alias). On 2026-09-19, a `platform` Integration became deployment-created only — the public create API rejects `kind=platform` — because Swallow manages only self-deployed Platforms ([decision 032](../../../decisions/032-self-deployed-platform-management.md)).
