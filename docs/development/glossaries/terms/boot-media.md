# Boot Media

- Bounded context: swallow-wide (Server, OS Provisioning). `api-server`, `dashboard`, and `cli` use this term with the same meaning.
- Definition: The swallow-served iPXE boot ISO that a Server's BMC mounts as virtual media and boots first, so the Server takes an address from the site's own network and then chains to the Site's provisioner — for networks where the provisioner cannot run DHCP.
- Allowed meaning: Two things under one name. (1) The installation's ISO: one file that swallow serves over HTTP at a URL the installation fixes (base URL plus a fixed path); operators never type an ISO URL per Server. (2) A Server's Boot Media setting: swallow-owned intent that the Server should boot the ISO first (`enabled` true or false), plus the outcome of the last apply. Enabling it is a **preflight**: swallow probes the BMC's Redfish capability, mounts the ISO, sets the boot override, and saves the setting only when all of that succeeded on that Server. Because a BMC may lose the mount or the override later, every OS Deployment on an enabled Server first runs an **ensure** Task that checks the BMC and re-applies what is missing. Disabling saves the setting and makes a best-effort attempt to eject the ISO and clear the override.
- Disallowed meaning: Not an OS Image and not what is installed on the Server; the ISO only gets the machine to the provisioner. Not the provisioner's own PXE or DHCP. Not the BMC's live state: whether the ISO is mounted now is read from the BMC, never assumed from the setting. Not a per-Server ISO URL.
- Synonyms: iPXE boot loader (operator wording); boot ISO.
- Deprecated terms: None.
- Examples: "`tainan-ci` lives on a network with its own DHCP, so an operator enables Boot Media on it; the preflight mounts swallow's iPXE ISO through Redfish and sets a continuous CD boot override." / "Before each RAM deploy of `tainan-ci`, the `ensure-boot-media` Task finds the ISO still mounted and the override still set, and succeeds without changing anything." / "The BMC lost the override after a firmware update; the next deploy's ensure Task sets it again."
- Related terms: BMC, Server, OS Deployment, Deploy Target, Task, Server Lock, OS Provisioning Provider.
- Change note: Added 2026-10-03 ([decision 047](../../../decisions/047-redfish-boot-media.md)) so Servers on externally served networks can be deployed without mounting an ISO by hand at every boot.
