# Pool

- Bounded context: swallow-wide. `api-server` and `dashboard` use this term with the same meaning.
- Definition: A swallow-owned, Site-scoped logical grouping of Servers used to partition resources for allocation and organization — a *resource pool* — that swallow defines and manages rather than merely observes. When the Site's provisioner supports an equivalent grouping (a MAAS *resource pool*), swallow realizes the Pool in that provisioner as it is created, renamed, deleted, or assigned; when the provisioner has no such capability, swallow still owns and manages the Pool locally.
- Allowed meaning: A managed record identified by an opaque, stable swallow-issued `poolId`, carrying a `name` that is unique within its Site, an optional `description`, and the `siteId` it belongs to. A Server may be assigned to at most one Pool at a time; the assignment is written through to the provisioner and its observed effect appears on the Server's provider-observed resource pool. Realization in the provisioner is best-effort by capability. "Pool" always means this swallow-owned resource pool concept; the phrase "available pool" in Release refers to the provider returning a Machine to its ready state and is not this term.
- Disallowed meaning: Not a Zone (a Zone groups for availability/fault/organization; a Pool partitions resources for allocation), not a Site, not a Kubernetes/Slurm Platform, not a provider's "available pool" of ready Machines used when releasing, and not the provisioner's opaque resource-pool label carried through untouched — that earlier opaque pass-through is superseded by this swallow-owned model.
- Synonyms: Resource Pool. (A MAAS "resource pool" is the provider realization of a Pool.)
- Deprecated terms: None.
- Examples: "Create a Pool `research` in the lab Site; MAAS gains a matching resource pool." / "Move `gpu-node-01` from Pool `default` to Pool `research`; the provisioner records the machine's pool and reconcile mirrors it onto the Server." / "'Release returns a Machine to the provider's available pool' does not refer to a Pool."
- Related terms: Zone, Site, Server, Integration, OS Provisioning Provider, Machine, Release.
- Change note: Added 2026-09-14 to make Pool (resource pool) a swallow-owned, Site-scoped managed concept surfaced under the dashboard *Infrastructure* area, with optional provider realization. Disambiguated from the pre-existing informal use of "available pool" in the Release term. See decision 029.
