# Docker Host Explorer

- Bounded context: Software Deployment (live management of a swallow-installed Docker CE).
- Definition: The live read/write management surface swallow offers for the Docker Engine on one Server, available only when swallow installed Docker CE on that Server with the Docker Engine API enabled. api-server calls the host's Engine API on demand; the objects it shows — Docker images, containers, volumes, and networks — are owned by the Docker Engine and never stored by swallow.
- Allowed meaning: Listing, pulling, and removing images; listing, creating, starting, stopping, restarting, and removing containers and reading a bounded log snapshot; listing, creating, and removing volumes and networks — each a synchronous call against the Engine API, never a Workflow. Eligibility is derived only from swallow-owned facts: the Server is `deployed` with a known primary address, its `docker-ce` Software Assignment is `installed`, and that assignment's `enableApi` variant is `true`. Writes are refused on a locked Server. A container's `state` is the Docker Engine's own value, passed through unchanged: `created`, `restarting`, `running`, `removing`, `paused`, `exited`, or `dead`. The Docker Engine's predefined networks `bridge`, `host`, and `none` cannot be removed.
- Disallowed meaning: Not a Software Assignment state or a Server status axis, and not evidence that Docker is healthy — the explorer reads the host live and its reachability says nothing about the assignment. Not a transparent Docker API proxy and not a browser connection to the host. Not a stored inventory: no image, container, volume, or network becomes a swallow entity or a Mongo document. Not the pending `Workload` / `Container` umbrella terms: a Docker container here is a Docker Engine object with Docker's state set, not swallow's planned workload model. Not available for a Docker API an operator enabled outside swallow, nor for Podman.
- Synonyms: Docker explorer. The dashboard labels it the "Containers" tab of the Server detail.
- Deprecated terms: None.
- Examples: "lab-control-2's Containers tab lists its images live from the Docker Engine; nothing is saved in swallow." / "An installation recorded before `enableApi` existed has no listener, so the explorer reports the API as disabled and offers to enable it." / "Stopping a container on a locked Server is refused; listing containers still works."
- Related terms: Managed Software, Software Assignment, Registry Credential, Server, Server Lock, Kubernetes Application.
- Change note: Added 2026-10-02 ([decision 043](../../../decisions/043-docker-host-management.md)) when the Docker CE `enableApi` variant and the api-server-mediated Docker explorer were introduced, following the live explorer plane of decision 032 and leaving the pending Workload/Container terms unresolved.
